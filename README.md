# Applied AI Tools Hub

My library of AI tools and n8n automation workflows, about 100 projects in one place. It includes lead scoring, resume analysis, fraud triage, SOP builders, Chrome research extensions and field-ops agents.

Each folder is its own project with its own README. Workflows are n8n JSON exports. Import them into n8n and add your own API keys.

Some of these are also used at [Zylos](https://zylos.us/automation.html).
